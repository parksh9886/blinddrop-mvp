SYSTEM GUIDE
This document reflects the exact status of the project as of January 29, 2026. Use this as context for future development sessions to ensure continuity.

1. Project Structure (File Tree)
src/pages
Actual files present in the directory:

LandingPage.tsx: Public landing page for unauthenticated users.
LoginPage.tsx: Authentication page (Supabase Auth). Supports `returnUrl` query parameter for smart redirects.
DashboardPage.tsx: Main artist dashboard. Manages tracks, views feedback. Merges `tracks` with `feedbacks_secure_view`.
ProfilePage.tsx: User settings page. Updates handle, bio, and avatar.
ArtistPublicPage.tsx: Public profile page (/u/:handle). Lists artist's tracks.
PublicFeedbackPage.tsx: Public track page (/track/:trackId). Fetches masked comments from `feedbacks_secure_view`.
src/components
Layout.tsx: Wrapper component providing consistent structure (Navbar + Main Content Area).
Navbar.tsx: Responsive navigation bar.
Logic:
Guest: Shows [Login] button with `returnUrl` parameter.
User: Shows "Avatar + Hamburger" menu (Dashboard, My Artist Page, Settings, Sign Out).
My Artist Page Link: Uses client-side <Link> to /u/{handle} (no new tab).
2. Database Schema (Inferred from Code)
The following schema is currently in use by the application logic.

users
id (uuid, PK) - Linked to Supabase Auth ID.
handle (text, unique) - Custom artist handle.
avatar_url (text) - Profile picture URL.
bio (text) - Artist biography.
tracks
id (uuid, PK)
user_id (uuid, FK -> users.id)
title (text)
url (text) - YouTube or SoundCloud URL.
platform (text) - 'youtube' | 'soundcloud'.
created_at (timestamptz)
feedbacks (Table)
id (uuid, PK)
track_id (uuid, FK -> tracks.id)
content (text) - The anonymous feedback text.
reply (text | null) - Artist's reply.
created_at (timestamptz)
is_unlocked (boolean)
feedbacks_secure_view (View)
Used for SELECT operations in public pages.
Returns masked content (e.g., "****") if the feedback is locked/unreplied to protect data at the network level.

4. Key Business Logic
Dashboard Logic (DashboardPage.tsx)
Data Fetching:
Fetches `tracks` for the user.
Fetches `feedbacks` separately from `feedbacks_secure_view` using `trackIds`, then merges them.
Feedback Sorting:
Feedbacks are displayed under each track.
Interaction:
Reply: Artist can reply. Updates `feedbacks` table directly.
Unlock: Updates `is_unlocked` in `feedbacks` table.
Copy Links:
Track Link: Copies origin/track/:trackId
Profile Link: Copies origin/u/:handle
Public Page Logic (PublicFeedbackPage.tsx)
Data Loading:
Queries `feedbacks_secure_view` to ensure locked content is masked (`****`) by the DB.
Visually blurs content if it is locked OR matches masked pattern (`****`).
Feedback Submission:
Inserts directly into `feedbacks` table (Write permission allowed).
Player:
Native <iframe> with regex parsing for YouTube/SoundCloud.
5. Current UI/UX Status
Navigation: Unified Header. Login redirects user back to the page they came from.
Styling: Dark Mode. Blurred text for locked feedback.
Responsiveness: Fully responsive.
